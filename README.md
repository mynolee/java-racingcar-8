# java-racingcar-precourse

## 구현 기능 목록

- 자동차 이름 입력 및 유효성 검증
    - 이름은 쉼표(,) 기준으로 구분
    - 이름 길이는 1자 이상, 5자 이하
    - 유효하지 않은 입력 시 IllegalArgumentException 발생

- 시도 횟수 입력 및 검증
    - 시도 횟수는 양의 정수만 가능
    - 잘못된 입력 시 예외 발생 후 프로그램 종료

- 자동차 전진 조건
    - 0~9 사이의 랜덤 값을 생성 (Randoms.pickNumberInRange(0, 9))
    - 값이 4 이상일 때 자동차가 전진

- 경주 결과 출력
    - 각 자동차의 이동 상황을 출력 (예: pobi : --)
    - 실행 결과를 모든 시도 횟수만큼 반복 출력

- 우승자 판정
    - 가장 멀리 이동한 자동차(들)를 우승자로 출력
    - 우승자가 여러 명일 경우 쉼표(,)로 구분하여 표시
